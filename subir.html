Llave de acceso

Esta página guarda los libros directamente en su página de GitHub. Para eso necesita una llave. Se pone una sola vez en cada teléfono o computadora.

  1. En GitHub, entra a Settings → Developer settings → Personal access tokens → Fine-grained tokens y pulsa Generate new token.
  2. Ponle un nombre (por ejemplo "bodega"), en Repository access elige Only select repositories y escoge lafleurdumal-absinthe.github.io.
  3. En Permissions → Contents elige Read and write. Pulsa Generate token y copia la llave.
